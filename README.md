# 秋招面试备战闪卡 · 供应链/跨境电商

> **线上访问地址**：[https://kevechang.github.io/zhudouya-interview/](https://kevechang.github.io/zhudouya-interview/)

专为 2027 届物流管理本科应届生打造的秋招面试备战单页应用（手机优先）。结合真实行业实战背景，聚焦 8 家精选供应链与跨境电商企业（拓竹科技、大寰机器人、越腾云创、鑫亚美运、欣旺达、摩罗志远等）及通用必备题库，收录 142 张高品质结构化面试闪卡与深度补习清单。

## 🌟 核心特性

- **手机优先体验**：触控目标 $\ge 44$px，3D Flip 真实翻牌动画，左右手势滑动手势切题；桌面端支持键盘快捷键（空格翻转、左右箭头切换、1/2 标记掌握度）。
- **结构化真题库**：涵盖 142 张深度打磨的面试闪卡，深度融合真实外资货代（德迅/得斯威）履约实操、全国物流设计大赛建模成果与学术项目经验，提供标准公式、算例与追问提示。
- **纯静态零依赖**：无前端框架、无 Node 构建步骤、无 CDN 外链、无第三方字体，纯原生 HTML5 + CSS3 + Vanilla JS，双击 `index.html` 即可运行。
- **隐私合规保护**：严格剥离个人隐私与敏感信息，以真实业务经历与数理模型支撑高信度面试表达。
- **断点记忆续刷**：基于 `localStorage` 本机持久化记录掌握进度，支持分类过滤、只看未掌握、顺序打乱与自定义二次确认进度重置。

## 🚀 本地预览方法

本项目为纯静态实现，支持以下两种便捷本地运行方式：

### 方法 1：直接双击打开（最简单）
直接使用文件管理器进入 `site/` 目录，双击 `index.html`，即可在任何现代浏览器中完整运行所有功能。

### 方法 2：使用本地轻量 HTTP 服务
在终端中执行以下命令：
```bash
cd site
python3 -m http.server 8080
```
然后在浏览器中访问 [http://localhost:8080/](http://localhost:8080/) 即可流畅体验。

## 📝 如何扩展与修改题库

所有题目与公司元数据均保存在 `site/data/` 目录下的纯 JS 脚本中，开箱即改、即刻生效：

### 1. 文件与公司对应关系
- `site/data/companies.js`：8 家目标公司的基本信息、薪资范围、匹配度、JD 原文、优势剖析与必须掌握的补习清单。
- `site/data/cards-common.js`：通用必备面试题（自我介绍、简历追问、行为面 STAR、通用英语、高情商反问）。
- `site/data/cards-<slug>.js`：各公司专属题库（`bambu`、`dh`、`yueteng-plan`、`xinyameiyun`、`sunwoda`、`yueteng-buy`、`yueteng-product`、`moluo`）。

### 2. 卡片数据结构规范
在各 `cards-*.js` 数组中追加对象：
```javascript
{
  id: "bambu-18",              // 全局唯一 ID
  cat: "专业硬技能",            // 固定 7 大枚举之一
  q: "面试官提出的问题描述",     // 题面
  a: "结构化回答（支持 **粗体**、- 列表、空行分段）",
  tip: "💡 面试官核心考察点与追问应对建议（可选）",
  en: false                    // 英文题目设为 true（可选）
}
```

**支持的 7 大题目分类枚举**：
1. `自我介绍与动机`
2. `专业硬技能`
3. `简历追问`
4. `情景与案例`
5. `行为面试`
6. `英语`
7. `反问环节`

### 3. 数据自检与校验
修改题库后，可在项目根目录下运行自检脚本以确保数据完整性与合规性：
```bash
node site/scripts/validate.js
```
该脚本将严格校验 ID 唯一性、分类枚举合法性、字段完整性与各卡组最低数量要求。
