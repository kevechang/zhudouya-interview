# 秋招面试备战闪卡 · 供应链/跨境电商

> **线上访问地址**：[https://kevechang.github.io/zhudouya-interview/](https://kevechang.github.io/zhudouya-interview/)

专为 2027 届物流管理本科应届生打造的秋招面试备战单页应用（手机优先）。结合真实行业实战背景，聚焦 8 家精选供应链与跨境电商企业（拓竹科技、大寰机器人、越腾云创、鑫亚美运、欣旺达、摩罗志远等）及通用必备题库，收录 142 张高品质结构化面试闪卡与深度补习清单。

## 🌟 核心特性

- **全站双模式自由切换**：支持顶部常驻分段器 `专业版 | 通俗版`，基于 `localStorage` (`zdy.mode.v1`) 无感持久化，点击即时原地重渲染（无需刷新页面）。
  - **专业版**：严谨规范的 JD 术语、标准化业务流程、工业级数理模型与专业外贸/物流公式；
  - **通俗版**：大白话拆解面试官意图（`qp`）、三段式口语化作答（`ap`：`**一句话说白了**` + `**打个比方**` + `**面试就这么说**`）与人话版追问避坑点（`tipp`），各岗位 JD 与 68 项核心考点均配备通俗速记笔记。
  - **闪卡卡背原地换看**：卡背底部提供「换看通俗版/专业版」轻量切换按钮，无需翻回正面、无需切题即可就地比对专业表达与人话逻辑。
  - **新手友好提示**：首页首访自动展示气泡横幅（「看不懂专业术语？右上角切『通俗版』」），支持一键切换并记录免打扰状态。
- **手机优先体验**：触控目标 $\ge 44$px，3D Flip 真实翻牌动画，左右手势滑动手势切题；桌面端支持键盘快捷键（空格翻转、左右箭头切换、1/2 标记掌握度）。
- **结构化真题库**：涵盖 142 张深度打磨的面试闪卡，深度融合真实外资货代（德迅/得斯威）履约实操、全国物流设计大赛建模成果与学术项目经验，提供标准公式、算例与追问提示。
- **纯静态零依赖**：无前端框架、无 Node 构建步骤、无 CDN 外链、无第三方字体，纯原生 HTML5 + CSS3 + Vanilla JS，双击 `index.html` 即可运行。
- **隐私合规保护**：严格剥离个人隐私与敏感信息，以真实业务经历与数理模型支撑高信度面试表达。
- **断点记忆续刷**：基于 `localStorage` 本机持久化记录掌握进度，支持分类过滤、只看未掌握、顺序打乱与自定义二次确认进度重置。

## 🚀 本地预览方法

本项目为纯静态实现，支持以下两种便捷本地运行方式：

### 方法 1：直接双击打开（最简单）
直接使用文件管理器进入 `site/` 目录，双击 `index.html`，即可在任何现代浏览器中完整运行所有功能。

### 方法 2：使用本地轻量 HTTP 服务
在终端中执行以下命令：
```bash
cd site
python3 -m http.server 8080
```
然后在浏览器中访问 [http://localhost:8080/](http://localhost:8080/) 即可流畅体验。

## 📝 题库与通俗版数据规范

所有题目与公司元数据均保存在 `site/data/` 目录下的纯 JS 脚本中，开箱即改、即刻生效：

### 1. 文件与公司对应关系
- `site/data/companies.js`：8 家目标公司的基本信息、薪资范围、匹配度、JD 原文、优势剖析、通俗版解读对象（`plain`）及 68 项考点补习清单（含 `plainNote`）。
- `site/data/cards-common.js`：通用必备面试题（自我介绍、简历追问、行为面 STAR、通用英语、高情商反问）。
- `site/data/cards-<slug>.js`：各公司专属题库（`bambu`、`dh`、`yueteng-plan`、`xinyameiyun`、`sunwoda`、`yueteng-buy`、`yueteng-product`、`moluo`）。

### 2. 卡片数据结构规范
在各 `cards-*.js` 数组中追加对象：
```javascript
{
  id: "bambu-18",              // 全局唯一 ID
  cat: "专业硬技能",            // 固定 7 大枚举之一
  q: "面试官提出的问题描述",     // 专业版题面
  a: "结构化专业版回答（支持 **粗体**、- 列表、空行分段）",
  tip: "💡 面试官核心考察点与追问应对建议（可选）",
  qp: "面试官其实想问：...",    // 通俗版人话意图（20–60 字）
  ap: "**一句话说白了**：...\n\n**打个比方**：...\n\n**面试就这么说**：...", // 通俗版三段式作答（120–300 字）
  tipp: "人话版考察点：... 可能追问：...", // 通俗版追问与考察点（20–80 字）
  en: false                    // 英文题目设为 true（可选）
}
```

**支持的 7 大题目分类枚举**：
1. `自我介绍与动机`
2. `专业硬技能`
3. `简历追问`
4. `情景与案例`
5. `行为面试`
6. `英语`
7. `反问环节`

### 3. 数据自检与校验
修改题库或通俗版内容后，可在项目根目录下运行自检脚本以确保数据完整性与合规性：
```bash
node site/scripts/validate.js
```
该脚本将严格校验：
- 全局 142 张卡片 ID 唯一性与分类枚举合法性；
- 各卡组最低题量与英语题数量底线；
- 通俗版字段字数限制（`qp` 20–60 字、`ap` 120–300 字包含 3 个粗体标记、`tipp` 20–80 字、`plainNote` 30–140 字）；
- 严禁违规主观评价词（`展现`、`体现候选人`、`出色`、`深厚`、`优秀`、`自洽`、`靠谱可信` 等）；
- 严禁 LaTeX 指令或未转换公式符号。
